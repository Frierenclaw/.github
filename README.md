# 🦋 Frieren AI Ecosystem

> *"It's the small, everyday efforts that build a legendary pipeline."*

An open-source, ultra-low latency framework designed to create highly interactive AI companions with real-time voice and 3D visual synchronization.

## 📐 The Party Members

* **[Fern](./fern) (The Pipeline):** Strict and reliable `pipecat-ai` orchestrator. Handles real-time audio streams, VAD, and schedules animation frames.
* **[Heiter](./heiter) (The Brain):** Wise memory keeper. A high-throughput FastAPI inference server that manages LLM generation and context streaming.

## 🛠 Magic Spells (Tech Stack)
`Python 3.14` • `Pipecat-ai` • `FastAPI` • `Tauri` • `Rust` • `Three.js` • `WebSockets`
